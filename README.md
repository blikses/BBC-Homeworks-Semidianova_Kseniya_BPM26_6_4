### Введение в специальность | ДЗ
Здравствуйте! Меня зовут Семидьянова Ксения, это мой репозиторий с домашними заданиями.

1. Дз 1: несколько видов калькуляторов (простейший калькулятор, калькулятор с помощью функции, непрерывный калькулятор и калькулятор высоты каблука, написанный с использованием класса)
2. Дз 2: преобразование cтрок в красивый вид с помощью 5ти различных уровней. Включает в себя: преобразование в верхний, нижний регистры; замену слова в строке с помощью replace; подсчет букв в слове; соединение и разделение строки с помощью join и split; проверка, является ли строка числом или содержит только буквы; удаление лишних пробелов и знаков
3. Дз 3: лабиринт. Реализован на двух массивах (один из них не доступен пользователю, так как в нем хранятся места мини-игр, которые пользователь должен найти самостоятельно). Реализованы: монстр (игра камень-ножницы-бумага с помощью random); ключ (пользователь решает примеры для получения); портал (в поле 3 на 3 пользователь выбирает координаты клетки и получает дополнительную жизнь, если угадывает, какая клетка была задана с помощью random); клад с доп. жизнью (отдается пользователю просто так, если он находит клетку). Управление с помощью кнопок (w, a, s, d); осуществляется проверка на положение робота, чтобы избежать столкновение со стеной
4. Дз 4: Pandas и Numpy. Подробный анализ полученных данных есть в readme в репозитории
5. Дз 5: PyQt и Tkinter. Реализовано мини-приложение, в котором пользователь может найти и/или изменить информацию о себе. Создана база данных users_db.db c таблицей people, в которой хранятся имя, фамилия и описание. Пользователь вводит свои имя и фамилию в приложение. Если их еще нет в бд, предлагается ввести их. Если поле будет оставлено пустым, в бд появится значение "Ничего неизвестно". Реализована проверка ошибок. Нельзя сохранить пустое имя или фамилию. Также нельзя поменять имя/фамилию в процессе изменения поля с описанием. Программа потребует сохранить новые имя и фамилию
